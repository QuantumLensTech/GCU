# Les 8 champs

GCU organise son analyse en 8 champs, chacun associé à une primitive et à un octant de la structure combinatoire (ℤ/2ℤ)³. La maturité de chaque champ n'est pas uniforme — elle suit une hiérarchie génératrice, pas un ordre arbitraire.

| Champ | Nom | Primitive | Octant | Maturité |
|---|---|---|---|---|
| GCU-G | Géométrie | EVAL | (−,−,−) | Seed / établi |
| GCU-A | Arithmétique | DERIVE | (+,−,−) | Établi |
| GCU-T | Topologie | COMPOSE | (−,+,−) | En réévaluation |
| GCU-C | Computation | INTEGRE | (+,−,+) | Seed / établi |
| GCU-S | Statistique | ACTIVATE | (−,+,+) | Établi |
| GCU-P | Physique | TRANSMIT | (+,+,+) | 3e émergence |
| GCU-Q | Quantique | MODE | (+,+,−) | Avancé |
| GCU-E | Éthique | VERIFY | (−,−,+) | 8e émergence |

## Hiérarchie génératrice

Les champs n'apparaissent pas tous au même niveau. Deux graines (GCU-G, GCU-C) engendrent un troisième champ (GCU-P), qui à son tour permet l'émergence de deux autres (GCU-A, GCU-S), eux-mêmes ouvrant sur les trois derniers (GCU-T, GCU-Q, GCU-E). Ce gradient de maturité reflète une structure de type Fibonacci dans l'ordre d'émergence, pas un jugement de valeur entre les champs.

## Sur le champ Binaire

Il n'y a pas de champ « Binaire » distinct — une révision d'avril 2026 l'a remplacé par GCU-T (Topologie) au même octant. Le binaire est une instanciation matérielle de GCU-C sous contrainte PEC (parity error correction), pas un champ à part entière : les primitives sont restées invariantes dans cette révision.

## Statut

Cette table décrit l'organisation du corpus, pas un résultat validé en bloc — le détail de ce qui est démontré, contraint ou encore ouvert pour chaque champ est documenté dans le corpus complet (non public à ce stade). Voir [`invariants.md`](invariants.md) pour ce qui est effectivement gelé par test indépendant.
